## 🚀 Быстрый старт

### Что понадобится

- Установленная платформа **1С:Предприятие**.
- XML-выгрузка конфигурации.
- Отдельная тестовая информационная база для первой загрузки и проверки.

### Установка

```bash
# 1. Подготовьте каталог с XML-исходниками
mkdir -p ~/projects/family-budget

# 2. Распакуйте архив с исходниками в этот каталог
#    (имя архива и путь замените на свои)
unzip ConfigFiles.zip -d ~/projects/family-budget

# 3. Откройте тестовую информационную базу в Конфигураторе 1С
# 4. Загрузите конфигурацию из файлов
# 5. Проверьте конфигурацию, обновите конфигурацию базы данных
# 6. Запустите 1С:Предприятие и проверьте основные сценарии
```

> Команды Linux выше показывают, как подготовить файлы. Сама загрузка XML-конфигурации выполняется средствами 1С:Предприятие; конкретные названия команд зависят от версии платформы.

**Важно:** перед загрузкой в существующую базу сделайте резервную копию. Для первого запуска используйте тестовую базу.

## 👨‍👩‍👧‍👦 Для пользователей

### 1. Подготовьте категории

Заполните справочники `КатегорииРасходов` и `ПодкатегорииРасходов`. Например, можно завести категории «Продукты», «Транспорт», «Жильё» и подходящие подкатегории.

### 2. Вносите покупки

Создавайте документ `Покупка` для регистрации расхода. Проверьте дату, сумму, категорию и остальные обязательные поля формы.

### 3. Отражайте поступления

Используйте документ `Пополнение`, чтобы фиксировать поступление денежных средств.

### 4. Проверяйте баланс

В конфигурации есть документы `РасчётныйПериод` и `СписываниеБаланса`. Перед регулярным использованием уточните их назначение и последовательность в интерфейсе и коде вашей версии.

### 5. Смотрите отчёты

| Отчёт | Для чего нужен |
|---|---|
| `ТратыЗаСегодня` | Просмотр трат за текущий день |
| `ТратыЗаЧисло` | Просмотр трат за выбранную дату |
| `ТратыПоДням` | Анализ расходов по дням |
| `СводнаяТаблицаПоМесяцам` | Сравнение данных по месяцам |
| `АнализПодкатегорий` | Анализ расходов по подкатегориям |
| `АнализЧленовСемьи` | Анализ по членам семьи |
| `ЗачисленияИТраты` | Сопоставление поступлений и расходов |
| `ПроверкаОстатков` | Контроль остатков |

Названия приведены по объектам конфигурации; набор фильтров и показатели проверяйте в самих отчётах.

### Где искать реализацию

В XML-выгрузке исходники модулей обычно располагаются в каталогах `Ext`:

| Что изучить | Типичный путь |
|---|---|
| Логика документа | `Documents/.../Ext/ObjectModule.bsl` |
| Логика формы | `Documents/.../Forms/.../Ext/Form/Module.bsl` |
| Общие функции | `CommonModules/.../Ext/Module.bsl` |
| Структура объектов | XML-файлы соответствующих объектов метаданных |

Фактические имена каталогов могут отличаться. Начните с модуля объекта документа, затем проследите движения по регистрам и запросы отчётов.

### Рекомендуемый цикл изменений

1. Сделайте резервную копию или создайте отдельную ветку Git.
2. Изучите модуль объекта и связанные регистры.
3. Внесите изменение.
4. Проверьте синтаксис и конфигурацию.
5. Проведите тестовые документы и сравните движения регистров.
6. Сверьте результаты отчётов с исходными операциями.
7. Проверьте изменение на копии базы до переноса в рабочую среду.

⚠️ **Осторожно с перепроведением.** Обработка `ПереПроводка` потенциально может менять движения документов. Сначала проверьте её на копии базы.
